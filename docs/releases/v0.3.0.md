# Display Mini 0.3.0 preview

Everyday controls join the compact menu bar panel:

* Mute monitor speakers and restore their last confirmed volume.
* Save, rename, apply and delete brightness/volume presets for connected displays.
* Point at a screen and use Control + Option + Command with arrow keys or M to adjust it.
* Apply the first three presets with Control + Option + Command + 1, 2 or 3.
* Change any shortcut from the keyboard button, save key/modifier choices, reset defaults, disable everyday keys, and inspect registration conflicts. Failed edits preserve the previous bindings; ⌃⌥⌘R remains a recovery fallback.
* Record a combination directly from the keyboard, review it and Save. Escape or switching away stops recording. Display actions pause while the shortcut editor has focus.
* Give screens custom names and restore their original labels from the gear beside each screen title.
* Star favorite resolutions, including refresh and pixel density variants. Available favorites appear first in the resolution menu and use the existing Keep/Revert preview.
* Open Advanced for optional linked brightness, monitor contrast, standard input switching with confirmation, and refresh rate selection that preserves the current resolution.

Presets skip missing screens, report partial failures and leave resolution/connection unchanged. Restore Displays remains available during application. Interrupted writes are re-read before another snapshot can be saved.

## Validation

Nineteen logic cases (153 assertions), five real store orchestration scenarios with simulated hardware, nine shortcut registration/persistence/recording scenarios, six helper process scenarios, and Objective-C protocol/identity checks pass. Build, toolchain checks, local signing verification and packaging pass.

Live checks on an M1 Pro with an LG IPS QHD confirmed monitor mute/unmute, saved preset application, rename, persistence across relaunch and deletion. The editable shortcut UI also passed save, relaunch persistence and reset checks. Recording passed native app input checks for capture/save, duplicate and reserved-key rejection, Escape cancellation and popover closure. These checks preserved the original display levels. Registration showed no shortcut conflicts; physical global keyboard delivery remains a separate validation item until confirmed.

Four personalization model scenarios and three store scenarios also pass. Native checks confirmed a custom screen name and resolution star survive app relaunch and appear in the resolution menu. The temporary name and star were removed afterwards. Light/dark sample views were inspected. Physical mode switching and unplugging were not repeated for this metadata update.

## Distribution limits

Advanced regression checks cover invalid inputs, contrast rollback, stale callbacks, linked edit persistence, preset isolation and input commands without readback. The local LG monitor returned valid 70% contrast but input zero, so this connection cannot use standard input switching. Physical contrast edits, input switching and refresh changes were not performed for this update.

Apple Silicon, macOS 14 or later. DDC volume requires monitor and connection support. Private macOS APIs and locally signed, non-notarized distribution remain preview limitations. Testing one setup does not certify all monitors or OS versions. This file is prepared release notes; creating a PR does not publish a GitHub release.
