# Display Mini v0.1.0

_Released 2026-10-08 as a preview_

Display Mini puts brightness, resolution, external monitor volume, and display connection switches in a compact native macOS menu bar panel. This first public release is open source under MIT and works independently of BetterDisplay.

## Highlights

* **Brightness:** native brightness or monitor DDC controls, with software dimming when needed.
* **Monitor volume:** adjust supported external monitor speakers directly.
* **Resolution previews:** choose a mode and keep it, or let the app attempt to revert after 15 seconds.
* **Connection controls:** disconnect and reconnect displays while protecting the last active screen.
* **Recovery:** Control + Option + Command + R restores owned display changes and removes dimming.

## Improvements

* Monitor capability detection, bounded communication timeouts, and confirmation reads after writes.
* Saved identity and resolution recovery records for retry after interruptions.
* Installation, usage, architecture, troubleshooting, contribution, and release documentation.
* Automated build checks and six logic tests with 32 assertions.

## Fixes

* Fixed a problem where a disconnected monitor lost its UUID and could not be found for reconnection.
* Fixed monitor response timing and packet handling that could produce invalid brightness readings.
* Fixed pending slider work reapplying dimming after recovery.
* Fixed previous resolution records being discarded or overwritten after failed recovery.
* Aligned the monitor helper and app deployment targets with macOS 14.

## Upgrade notes

Requires Apple Silicon and macOS 14 or later. Download the arm64 ZIP, verify its matching checksum if desired, expand it, and move the app to Applications. Quit a running copy before replacing it, and avoid running competing display utilities.

This is a preview, not a broadly hardware-validated release. Local testing covered launch, the panel, native discovery, LG DDC reads, and a disconnect/recovery investigation. Automated checks cover logic and builds rather than physical monitors. Hardware writes and resolution changes have not been exhaustively validated.

The app uses private macOS APIs. The download is locally signed but is not Developer ID signed or notarized, so macOS may block it. Building from source is also supported. See the installation and troubleshooting guides in the repository.
